# CLAUDE.md — гид по репозиторию для будущих сессий

Этот репозиторий содержит **систему ИИ-агентов Claude Code для поиска и монетизации
партнёрских (аффилиатных) программ**. Полное описание — в `affiliate/README.md`,
пошаговый запуск для пользователя — в `affiliate/START-HERE.md`. Прочитай оба перед работой.

## Что это

Конвейер из субагентов (`.claude/agents/*.md`), которые: ищут партнёрские программы по
регионам → критически отбирают реально прибыльные → готовят продвижение (клиенты + контент)
→ ведут учёт дохода → самообучаются на фактах. Регион по умолчанию — US/Global.

## Структура

- `.claude/agents/` — 7 субагентов: `affiliate-orchestrator`, `affiliate-scout`,
  `affiliate-analyst`, `affiliate-growth`, `affiliate-traffic`, `affiliate-content`,
  `affiliate-learner`.
- `affiliate/knowledge-base/programs.csv` — реестр программ (42 шт.), 17 колонок. **Это CSV:
  правь только через `csv`-парсер/`csv.writer` (поля с запятыми должны быть в кавычках).
  Ручная дозапись строк уже ломала выравнивание колонок — не повторяй.**
- `affiliate/knowledge-base/revenue.csv` — фактический доход (единственный источник правды
  о прибыли). Пока все нули → «рано судить».
- `affiliate/knowledge-base/criteria.md` — критерии отбора (обновляет `affiliate-learner`).
- `affiliate/reports/` — promo-планы, traffic-планы, шорт-листы.
- `affiliate/content/<Программа>/` — черновики статей/скриптов (16 шт. по 7 лидерам).
- `affiliate/tools/` — `income-calculator.html` и `dashboard.html` (публикуются как Artifacts).

## Как запускать конвейер

Оркестрация идёт с ВЕРХНЕГО уровня (главная сессия или пользователь), поэтапно:
1. `affiliate-scout` — поиск по региону/нише → дописывает `programs.csv` (status=new).
2. `affiliate-analyst` — анализ+решение → заполняет score/decision/status.
3. `affiliate-growth` — promo-план по selected + учёт в `revenue.csv`.
4. `affiliate-traffic` и `affiliate-content` — клиенты/трафик и материалы по promo-планам.
5. `affiliate-learner` — когда в `revenue.csv` появятся реальные paid-суммы: сверяет
   прогноз с фактом, обновляет `criteria.md`.

⚠️ **Ограничение среды: субагент не может запускать субагентов.** `affiliate-growth` не
делегирует сам — он готовит promo-план и возвращает запрос, а `affiliate-traffic`/
`affiliate-content` запускает верхний уровень. Не жди «одна команда → вся цепочка сама».

## Незыблемые правила (honesty)

1. Факты — только с источником (URL). Нет источника → это гипотеза, помечай как гипотезу.
2. «Приносит прибыль» = только фактически выплаченные (paid) суммы из `revenue.csv`,
   не обещания программ и не прогнозы.
3. Не выдумывать ставки, лимиты, причины. Не нашёл — пиши «не найдено».
4. В контенте: обязательный affiliate-disclosure, плейсхолдер `{{AFF_LINK}}` вместо
   реальной ссылки, цены за пометкой «verify on <офиц. сайт>». Никаких обещаний дохода/
   трудоустройства/«100% анонимности». Ничего не публиковать/не рассылать без явного
   согласия пользователя.
5. Egress-прокси среды часто блокирует официальные домены брендов → часть ставок из
   вторичных источников. Помечай такие как «не подтверждено офиц.».
