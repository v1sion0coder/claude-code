# 🍼 Пошагово, как для новичка: с чего начать и что куда вписывать

Без жаргона. Делай строго по порядку. Начни с **одной** программы (Webflow) — освоишь, добавишь остальные.

---

## Что ты вообще делаешь (одним предложением)
Ты пишешь честный обзор продукта → человек читает → переходит по твоей особой ссылке → покупает → компания платит тебе процент. **С человека ты денег не берёшь.**

---

## ШАГ 1. Заведи площадку, где будет статья (1 раз)
Нужен блог. Самый простой бесплатный старт:
- Вариант А (проще всего): **Medium** — https://medium.com → «Sign up» → пиши статьи бесплатно.
- Вариант Б (лучше для денег на будущее): свой блог на WordPress — купи домен+хостинг (~$3–5/мес), напр. https://hostinger.com или https://wordpress.com/start
👉 Для первого раза бери **Medium**, чтобы не застрять.

## ШАГ 2. Вступи в партнёрскую программу (начни с Webflow)
1. Открой: **https://webflow.com/solutions/affiliates**
2. Нажми «Become an affiliate» / «Join» → зарегистрируйся (это партнёрская сеть **PartnerStack**).
3. Заполни профиль, укажи свой блог (из Шага 1).
4. Дождись одобрения (обычно быстро). ⚠️ Некоторые программы (Shopify, HubSpot) одобряют только после 2–3 опубликованных статей — поэтому Webflow первым, он проще.
5. В кабинете PartnerStack найди свою **партнёрскую ссылку** (Referral link). Она выглядит примерно так: `https://webflow.grsm.io/твой-код`. **Скопируй её.**

## ШАГ 3. Возьми готовую статью и вставь свою ссылку
1. Открой готовый черновик: файл `affiliate/content/Webflow/webflow-vs-wordpress.md` (в этом репозитории на GitHub).
2. Найди в тексте `{{AFF_LINK}}` (это плейсхолдер-заглушка).
3. **Замени ВСЕ `{{AFF_LINK}}` на свою ссылку из Шага 2.**
4. Найди пометки «verify on webflow.com» и подставь реальные цифры цен с сайта Webflow (просто проверь их там сейчас).
5. Оставь блок про «affiliate disclosure» вверху — это обязательно по закону (говорит читателю, что ссылка партнёрская).

## ШАГ 4. Опубликуй
1. Скопируй готовый текст статьи в Medium (или свой блог) → «Publish».
2. Готово — статья работает 24/7. Сделай так же со второй статьёй: `affiliate/content/Webflow/webflow-review-2026-script.md`.

## ШАГ 5. Раз в неделю вписывай цифры (это самое важное!)
Открой файл `affiliate/knowledge-base/revenue.csv`. Там уже есть строки. Цифры бери из кабинета PartnerStack/Impact.
Заполняй только 5 столбцов, остальное не трогай:

| Столбец | Что вписать (простыми словами) |
|---|---|
| `clicks` | сколько людей кликнули по твоей ссылке |
| `conversions` | сколько из них купили |
| `approved` | сумма $, которую тебе начислили (ещё не на руках) |
| `paid` | сумма $, которую **реально выплатили** тебе ← это твоя прибыль |
| `spend` | сколько ты потратил $ (домен, хостинг, реклама) |

**Пример заполненной строки** (когда появятся данные):
```
Webflow,SEO-блог (сравнения/обзоры),2026-10,320,3,138,0,12,,,рано судить
```
(320 кликов, 3 продажи, начислено $138, выплачено пока $0, потрачено $12).

Столбцы `net_profit`, `roi`, `result_class` оставь пустыми/как есть — я пересчитаю, когда попросишь.

## ШАГ 6. Позови меня обновить выводы
Когда в столбце `paid` появятся реальные суммы (>0) — напиши мне «запусти learner».
Я сверю прогноз с фактом и подскажу, какие программы реально приносят деньги, а какие бросить.
