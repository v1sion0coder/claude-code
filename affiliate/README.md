# Система ИИ-агентов для поиска и монетизации партнёрских программ

Набор субагентов Claude Code, которые автоматизируют полный цикл: от поиска
аффилиатных программ по регионам до критического отбора реально прибыльных и их
продвижения, с самообучением между циклами.

## Агенты и этапы

| Этап | Агент | Что делает |
|---|---|---|
| 0. Координация | `affiliate-orchestrator` | Разбивает цель на этапы, вызывает остальных по очереди |
| 1. Поиск | `affiliate-scout` | Ищет кандидатов по региону, собирает факты с источниками |
| 2. Анализ | `affiliate-analyst` | Критически проверяет реальность выплат, репутацию, красные флаги |
| 3. Решение | `affiliate-decider` | Ранжирует и отбирает то, что реально стоит тестировать/масштабировать |
| 4a. Продвижение | `affiliate-promoter` | План трафика, контент, офферы под регион (может звать Canva/ElevenLabs/Apollo/Gmail) |
| 4b. Учёт дохода | `affiliate-revenue-tracker` | Фактические метрики: выплаты, расходы, чистая прибыль |
| 5. Самообучение | `affiliate-learner` | Сравнивает прогноз с фактом, переписывает критерии отбора |

Этапы 4–5 — замкнутый цикл: **доход → факты → уточнённые критерии → следующий поиск точнее.**

## Как запустить

В Claude Code в этом репозитории:

```
Запусти affiliate-orchestrator: полный цикл по региону <страна/рынок>, ниша <опц.>
```

Или вызывай агентов поштучно, например:

```
Используй affiliate-scout, чтобы найти партнёрки в регионе Германия, ниша финтех
```

Агенты подхватываются автоматически из `.claude/agents/`.

## Файлы данных

- `knowledge-base/programs.csv` — единый реестр программ и их статусов (жизненный цикл:
  `new → analyzed → selected/rejected/reserve → результат`).
- `knowledge-base/revenue.csv` — фактические доходы/расходы (единственный источник правды
  о прибыли).
- `knowledge-base/criteria.md` — критерии отбора; обновляются агентом обучения.
- `knowledge-base/lessons.md` — уроки по регионам (создаёт learner).
- `reports/` — отчёты по этапам и регионам.

## Принципы честности (заложены во всех агентов)

1. **Факты — только с источником.** Нет источника → это гипотеза, помечается как гипотеза.
2. **«Приносит прибыль» = только фактически выплаченные суммы** из `revenue.csv`,
   не обещания программ и не прогнозы.
3. **Не выдумывать** ставки, лимиты, причины. Не нашёл — так и пишем «не найдено».
4. **Критический скепсис по умолчанию:** красивые обещания и высокие ставки — повод
   проверять тщательнее, а не доверять.
5. Небольшая стабильная подтверждённая прибыль ценится выше крупных неподтверждённых обещаний.

## Подключение других ИИ / инструментов

`affiliate-promoter` при наличии в сессии может задействовать MCP-коннекторы:
Canva (креативы), ElevenLabs (озвучка/видео), Apollo.io (лиды), Gmail (аутрич).
Любая внешняя отправка/публикация — только с явного согласия пользователя и по правилам площадок.

## Ограничения (честно)

- Система не может *гарантировать* прибыль. Она повышает шансы за счёт отсева мусора и
  обучения на фактах.
- Достоверность зависит от качества источников в вебе и от того, вносит ли пользователь
  реальные цифры выплат в `revenue.csv`.
- Юридические и налоговые аспекты партнёрского заработка в конкретном регионе — вне
  компетенции агентов; проверяйте отдельно.
