# Промты для GPT (второй ИИ-помощник)

GPT здесь — **второй копирайтер/редактор и генератор идей**. Он, как и Claude, **не может**
публиковать, вставлять твои реальные партнёрские ссылки, брать реальные скриншоты или
гарантировать доход (нет доступа к твоим кабинетам). Используй его для текста и идей.

---

## Промт 1 — «какую роль ты можешь взять» (общий, вставь первым)

```
Контекст: я запускаю партнёрский (аффилиатный) маркетинг. Ниши уже отобраны по
реальной экономике, упор на recurring-SaaS (Webflow, Systeme.io, Thinkific, HubSpot,
Semrush, ElevenLabs/Murf). Модель: пишу честные обзоры/сравнения → читатель переходит
по моей партнёрской ссылке → покупает → сервис платит мне комиссию. Я новичок,
работаю как частное лицо, стартую на бесплатном органическом трафике (SEO-блог +
YouTube), без платной рекламы. Черновики статей у меня уже есть.

Принципы, которых я держусь: только честные факты с источниками; никаких обещаний
гарантированного дохода; обязательный affiliate-disclosure; цены проверяю на офиц. сайте.

Вопрос: какую РОЛЬ ты можешь взять в этом проекте и где реально помочь? Дай короткий
список конкретных задач, которые ты потянешь (например: идеи заголовков, подбор
ключевых запросов, вычитка/усиление текста, структура блога, план публикаций,
FAQ-блоки, идеи для видео-скриптов). Отметь честно, чего ты делать НЕ можешь
(публиковать, вставлять мои реальные ссылки, давать юридические/налоговые гарантии).
Не выдумывай цифры и ставки — если чего-то не знаешь, так и скажи.
```

## Промт 2 — «GPT-редактор статьи» (под конкретный текст)

```
Ты — редактор партнёрского контента. Я дам черновик обзора/сравнения продукта.
Задача: усилить его, не нарушая правил:
- Сохрани affiliate-disclosure и плейсхолдер {{AFF_LINK}} на месте (не заменяй ссылку).
- Не выдумывай цены, цифры, бенчмарки — если их нет, оставь пометку «verify on <сайт>».
- Честно: реальные плюсы И минусы, без обещаний дохода/результата.
- Улучши заголовок (5 вариантов), структуру H2/H3, введение и CTA.
- Предложи 8–10 целевых поисковых запросов с пометкой интента (сравнение/«best»/«review»).
- Укажи, что проверить перед публикацией.

Вот черновик:
[ВСТАВЬ СЮДА ТЕКСТ ИЗ affiliate/content/<Программа>/<файл>.md]
```

## Промт 3 — «идеи и ключи под нишу» (планирование)

```
Ниша: [например, no-code конструкторы сайтов]. Продукт, который продвигаю: [Webflow].
Аудитория: [кто это, какие боли]. Дай:
- 15 тем статей с высоким коммерческим интентом (сравнения, «worth it», «alternatives»);
- к каждой — целевой запрос и тип (comparison/review/best-of/how-to);
- 5 идей коротких видео (YouTube/Shorts).
Только реалистичное; не выдумывай search volume — помечай оценки как оценки.
```

Готовые черновики для Промта 2 лежат в `affiliate/content/`. Реестр программ и решения —
в дашборде и `affiliate/knowledge-base/programs.csv`.
