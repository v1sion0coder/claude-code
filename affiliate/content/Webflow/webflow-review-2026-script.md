**[0:30–1:30] What is Webflow, in plain terms**
"Webflow is a visual website builder — but unlike Wix or Squarespace, it's built for people who want real design control, closer to what a developer could do with actual CSS, just through a visual canvas instead of code. It also has a built-in CMS for blogs and dynamic content, and separate plans for online stores. [Screen recording: show the Webflow Designer canvas, point out the layout/style panels.]"

**[1:30–3:30] What it does well**
- "Design control: you can adjust things like flexbox and grid layouts, spacing, and interactions with real precision — not just 'drag this box here.' [Screen recording: show building a simple section, adjusting spacing/responsive breakpoints.]"
- "Hosting is included and managed — you don't touch a separate hosting account, and you don't have to think about plugin updates or server security like you would with WordPress."
- "The output tends to be clean, and the platform has a solid technical SEO foundation out of the box — though your actual rankings still depend on your content and SEO work, not the platform alone."

**[3:30–5:30] Where it genuinely falls short (be specific, no vague hedging)**
- "The learning curve is real. If you've never touched CSS concepts like flexbox or box model, expect to spend real hours in Webflow University before you're comfortable — this is not a 'set it up in twenty minutes' tool the way Wix or Squarespace can be for a basic site."
- "The app/integration ecosystem is smaller than WordPress's. If there's a very specific feature you need, there's a good chance a WordPress plugin exists for it and no direct Webflow equivalent."
- "If serious ecommerce is your main goal, Webflow's Ecommerce plans are usable but generally not as feature-rich as WooCommerce or a dedicated platform like Shopify — I'd point ecommerce-first builders elsewhere."
- "Migrating off Webflow later is more involved than moving a self-hosted WordPress site — worth thinking about before you build something large on it."

**[5:30–7:00] Pricing, honestly**

What I will say: budget for the CMS/Workspace tier if you need blog or dynamic content, because the base Site plan alone won't cover that, and it's an easy thing to underestimate."
